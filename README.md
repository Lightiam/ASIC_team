# ASIC_team

Consolidating codes

This repository is intended to hold consolidated code and resources for the ASIC team.

Getting started

- Clone the repository: `git clone git@github.com:Lightiam/ASIC_team.git`
- Create a branch for your work: `git checkout -b feat/your-feature`
- Commit and open a pull request against `main`.

Contributing

Please follow a lightweight workflow:
- Use feature branches (branch names like `feat/...`, `fix/...`, `chore/...`).
- Open pull requests and request a review.
- Keep commits small and descriptive.
